# Awesome Optical-to-SAR Translation

A curated collection of research papers and methods related to optical-to-SAR image translation.

This repository accompanies our survey on optical-to-SAR translation and organizes representative methods according to the proposed taxonomy. It includes methods studied for optical-to-SAR translation and general-purpose techniques with potential transferability.
